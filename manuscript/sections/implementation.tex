\section{Implementation}

\subsection{Architecture}

\textit{qPCRtools} is written in C++17 and built on Qt6 \cite{qt}, which
provides cross-platform abstractions and the native application shell. The
user interface is rendered with web technologies---Bootstrap~5.3 for layout
and Apache ECharts \cite{echarts} for interactive charts---hosted inside a
\texttt{QWebEngineView}, and exchanges data with the native backend through
Qt~WebChannel via a registered bridge object. This separation lets the
presentation layer iterate rapidly as HTML, CSS, and JavaScript while all
numerical computation stays in compiled native code. The analytical core is
isolated as a standalone static library, \texttt{qpcr\_core}, which depends
only on Qt~Core and Eigen and is independent of the GUI; it is exercised
directly by the unit-test suite and is also linked by the command-line
equivalence driver described in Results. Statistical distribution functions
use the GNU Scientific Library (GSL) for accuracy. The resulting interface
is shown in Figure~\ref{fig:overview}.

\subsection{Quantification algorithms}

The core reimplements the analytical methods of the R package. From a
dilution series, amplification efficiency is obtained by ordinary least
squares of $C_q$ on $\log_{10}(\text{concentration})$, yielding slope $s$,
intercept, $R^2$, and a regression $p$-value; efficiency is
\begin{equation}
E = d^{-1/s} - 1,
\end{equation}
where $d$ is the dilution factor. Relative expression is computed by the
$\Delta C_t$ and $\Delta\Delta C_t$ methods \cite{livak2001analysis},
\begin{equation}
\mathrm{RE} = 2^{-\big[(C_{q,\mathrm{target}}-C_{q,\mathrm{ref}})_{\mathrm{treated}}
- (C_{q,\mathrm{target}}-C_{q,\mathrm{ref}})_{\mathrm{control}}\big]},
\end{equation}
and by an efficiency-based (RqPCR) method \cite{rancurel2019satqpcr} in which
per-sample quantities are $E^{\,C_{q,\min}-C_q}$ and are normalized by the
geometric mean of one or more reference genes \cite{pfaffl2001new}.

\subsection{Statistical analysis}

For each target gene the application compares groups with independent,
paired, or Welch two-sample $t$-tests, the Wilcoxon rank-sum or signed-rank
test, or one-way ANOVA followed by Tukey's HSD post-hoc letter grouping. It
additionally reports Cohen's $d$ effect sizes, Shapiro--Wilk normality
testing, and IQR-based outlier removal, and can select reference genes
automatically by the geNorm algorithm \cite{vandesompele2002accurate}. These
options extend the original R package, which provided $t$-test and
ANOVA/Tukey testing only.

\subsection{Software engineering and scope}

\textit{qPCRtools} is managed with CMake and ships with a unit-test suite.
Visualization follows a ggplot2-inspired aesthetic \cite{wickham2016ggplot2}
with configurable color palettes and significance annotations; the interface
is bilingual (Chinese/English) and accepts both CSV and Excel input. The
application is distributed as a single self-contained executable for Windows
and macOS, requiring no R, Python, or runtime installation, and the source
compiles on Linux. It is released under the MIT license. Two R functions are
not yet ported---the standard-curve slope--intercept quantification
(\texttt{CalExpCurve}) and the reverse-transcription reagent volume
calculation (\texttt{CalRTable})---and are planned for a future release.
