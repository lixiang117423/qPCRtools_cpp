\section{Implementation}

\subsection{Architecture}

\textit{qPCRtools} is written in C++17 and built on Qt6 \cite{qt}, which
provides cross-platform abstractions and the native application shell. The
user interface is rendered with web technologies---Bootstrap~5.3 for layout,
with Apache ECharts \cite{echarts} bundled for the figure view---hosted inside
a \texttt{QWebEngineView}, and exchanges data with the native backend through
Qt~WebChannel via a registered bridge object. This separation lets the
presentation layer iterate rapidly as HTML, CSS, and JavaScript while all
numerical computation stays in compiled native code. The analytical core is
isolated as a standalone static library, \texttt{qpcr\_core}, which depends
only on Qt~Core and Eigen and is independent of the GUI; it is exercised
directly by the unit-test suite and is also linked by the command-line
equivalence driver described in Results. Statistical distribution functions
use the GNU Scientific Library (GSL) for accuracy. The resulting interface
is shown in Figure~\ref{fig:overview}.

\subsection{Quantification algorithms}

The core reimplements the analytical methods of the R package. From a
dilution series, amplification efficiency is obtained by ordinary least
squares of $C_q$ on $\log_{d}(\text{concentration})$, i.e.\ on the number of
$d$-fold dilution steps ($d$ = dilution factor, 4 in the bundled example),
yielding slope $s$, intercept, $R^2$, and a regression $p$-value; efficiency is
\begin{equation}
E = d^{-1/s} - 1,
\end{equation}
with $s$ expressed per $\log_d$ unit (equivalently, per dilution step).
Relative expression is computed by the
$\Delta C_t$ and $\Delta\Delta C_t$ methods \cite{livak2001analysis},
\begin{equation}
\mathrm{RE} = 2^{-\big[(C_{q,\mathrm{target}}-C_{q,\mathrm{ref}})_{\mathrm{treated}}
- (C_{q,\mathrm{target}}-C_{q,\mathrm{ref}})_{\mathrm{control}}\big]},
\end{equation}
and by an efficiency-based (RqPCR) method \cite{rancurel2019satqpcr} in which
per-sample quantities are $E^{\,C_{q,\min}-C_q}$ and are normalized by the
geometric mean of one or more reference genes \cite{pfaffl2001new}.

\subsection{Statistical analysis}

For each target gene the application compares groups statistically. The core
library implements two-sample $t$-tests with and without the Welch
variance correction, the paired $t$-test, the Wilcoxon rank-sum and
signed-rank tests, and one-way ANOVA followed by Tukey's HSD post-hoc letter
grouping, and it reports Cohen's $d$ effect sizes alongside the $t$-test
results; it also supports IQR-based outlier removal and automatic
reference-gene selection by the geNorm algorithm
\cite{vandesompele2002accurate}. These options extend the original R package,
which provided $t$-test and ANOVA/Tukey testing only. The graphical interface
currently exposes the Welch two-sample $t$-test, the Wilcoxon rank-sum test
and one-way ANOVA with Tukey's HSD; the paired $t$-test and the Wilcoxon
signed-rank test are exercised by the test suite but are not yet offered as
interface options.

\subsection{Software engineering and scope}

All results are presented as tables that can be exported as CSV or Excel for
further plotting, and groups that differ significantly are labelled with
Tukey letters directly in the result table. Version~1.1.0 does not render
figures: the ECharts-based figure view is present in the code base but
disabled, and the figures of this paper were therefore produced from the
application's numerical output by the plotting script shipped in the
repository (\texttt{validation/plot\_examples.py}), not by the graphical
interface. \textit{qPCRtools} is managed with CMake and ships with a
unit-test suite; the interface
is bilingual (Chinese/English) and reads CSV input as well as Excel
(\texttt{.xlsx}) workbooks when built against the optional OpenXLSX
dependency. The application is distributed as a single self-contained
executable for Windows and macOS, requiring no R, Python, or runtime
installation, and the source compiles on Linux. It is released under the MIT
license. Two R functions are not yet ported---the standard-curve
slope--intercept quantification (\texttt{CalExpCurve}) and the
reverse-transcription reagent volume calculation (\texttt{CalRTable})---and
are planned for a future release.
