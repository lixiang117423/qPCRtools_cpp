\section{Availability and implementation}

Implementation: \textit{qPCRtools} is a C++17/Qt6 desktop application built
with CMake ($\geq$~3.20); the core algorithm library requires only Qt~Core and
optionally links Eigen3, GSL and OpenXLSX, while the interface requires
Qt~WebEngine and WebChannel. It is distributed as a single self-contained
executable for Windows and macOS---no R, Python or other runtime, and no
registration, are needed to download or run it. The macOS binary is built for
Apple Silicon, requires macOS~12 or newer, and is ad-hoc signed but not
notarized. Linux builds are supported by the source and build scripts but are
not part of the released binary set.

Availability: the source code is freely available under the MIT license at
\url{https://github.com/lixiang117423/qPCRtools_cpp}. Pre-built binaries for
version~1.3.0 and the matching source tag are in the repository releases. The
repository includes documentation, a unit-test suite, example datasets, the
published-data re-analysis used in this paper and a fully reproducible
validation package (\texttt{validation/}) comprising a base-R reference, a C++
command-line driver linked against \texttt{qpcr\_core}, and a comparison
script that regenerates all validation outputs and figures. We will keep the
software and its source code available for at least two years after
publication. Supplementary Figures~S1--S2 and Supplementary Tables~S1--S2
are available online only.
