\section{Availability}

The source code and pre-built binaries for Windows and macOS are available
at \url{https://github.com/lixiang117423/qPCRtools_cpp} under the MIT
license. The repository includes documentation, a unit-test suite, example
datasets, and a fully reproducible equivalence-validation package
(\texttt{validation/}) comprising the R script, a C++ command-line driver
linked against \texttt{qpcr\_core}, and a comparison script that regenerates
all validation outputs and figures. The project builds with CMake
($\geq$~3.20), requires a C++17 compiler and Qt~6 ($\geq$~6.5) with the
WebEngine and WebChannel modules, and optionally links Eigen3 and GSL.
